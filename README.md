# Software Engineering Quiz

Thai-language interactive quiz application covering Software Engineering fundamentals (Chapters 1-7). 50 multiple-choice questions with instant feedback.

## Topics Covered

- Software Process Models (Waterfall, Spiral, RUP)
- Agile / Scrum methodology
- Project Management (WBS, PERT/CPM, RACI)
- Requirements Engineering (SRS, functional vs non-functional)
- UML Diagrams (Use Case, Class, Sequence, Deployment, ER, DFD, BPMN)
- Design Principles (cohesion/coupling, abstraction, modularity, refactoring)

## Features

- 50 multiple-choice questions
- Thai language UI (TH Sarabun New font)
- Score tracking and progress display
- Correct/incorrect visual feedback (green/red highlights)
- Previous/next navigation with answer persistence
- Responsive design with Tailwind CSS

## Tech Stack

- HTML, CSS, JavaScript
- Tailwind CSS (CDN)

## Usage

Open `index.html` in a browser — no build step required.

Deploy to GitHub Pages for online access.

## Deployment

This is a static site ready for GitHub Pages:

1. Push to `username.github.io` repository
2. Enable GitHub Pages in repository settings
3. Site is live at `https://username.github.io`
